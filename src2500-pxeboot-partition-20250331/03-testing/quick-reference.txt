## 快速检查命令

### 1. 分区检查
```bash
lsblk -o NAME,SIZE,PARTLABEL,MOUNTPOINT | grep -E "(pxe_|log)"
```
**预期**: 显示 4 个 PXE 分区

### 2. 挂载点检查
```bash
mount | grep -E "(pxe_|log)"
```
**预期**: 所有分区已挂载

### 3. systemd 服务检查
```bash
systemctl list-units '*.mount' | grep -E "(pxe|log)"
```
**预期**: 显示 4 个 active (mounted) 状态

### 4. 分区大小检查
```bash
lsblk -o NAME,SIZE,PARTLABEL | grep -E "(pxe_|log)"
```
**预期**:
- pxe_rootfs_a: 2G
- pxe_rootfs_b: 2G
- pxe_upper: 28G
- log: 80G (取决于 eMMC)

### 5. 日志检查
```bash
journalctl -u pxeboot-init.service -n 50 --no-pager
```
**预期**: 无错误或警告

## 常见问题排查

### 问题: 分区未创建
**检查**:
```bash
systemctl status pxeboot-init.service
journalctl -u pxeboot-init.service
```

### 问题: 分区未挂载
**检查**:
```bash
systemctl status pxe\x2drootfs\x2da.mount
cat /etc/systemd/system/pxe\x2drootfs\x2da.mount
```

### 问题: 文件系统只读
**检查**:
```bash
mount | grep pxe
df -h | grep pxe
```
