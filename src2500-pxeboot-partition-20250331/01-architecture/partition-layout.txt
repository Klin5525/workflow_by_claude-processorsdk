## 与 SRC3600 对比

```
SRC3600 (64GB eMMC):
├─ 系统分区 (0~16GB)          [相同]
├─ AP 分区 (16~96GB)          [不同]
│  ├─ ap0_rootfs_a (1GB)
│  ├─ ap0_rootfs_b (1GB)
│  ├─ ap1_rootfs_a (1GB)
│  ├─ ap1_rootfs_b (1GB)
│  ├─ ap0_upper (18GB)
│  └─ ap1_upper (10GB)
└─ log 分区 (96~64GB)         [不同]

SRC2500 (64GB eMMC):
├─ 系统分区 (0~16GB)          [相同]
├─ PXE 分区 (16~48GB)         [简化]
│  ├─ pxe_rootfs_a (2GB)      [增大]
│  ├─ pxe_rootfs_b (2GB)      [增大]
│  └─ pxe_upper (28GB)        [合并]
└─ log 分区 (48~64GB)         [提前]
```

## 挂载点布局

```
/ (根文件系统)
├─ /boot                     → boot 分区 (只读)
├─ /oem                      → oem 分区 (厂商配置)
├─ /userdata                 → userdata 分区 (用户数据)
├─ /pxeboot                  → pxeboot 分区 (PXE 导出根)
│  ├─ /pxe_rootfs_a          → pxe_rootfs_a 分区 (A)
│  ├─ /pxe_rootfs_b          → pxe_rootfs_b 分区 (B)
│  ├─ /pxe_upper             → pxe_upper 分区 (Overlay)
│  └─ /lower                 → pxe_rootfs_a/b (NFS 导出)
└─ /log                      → log 分区 (日志)
```

## OverlayFS 层叠结构

```
                   ┌─────────────────────┐
                   │  NFS 客户端看到的   │
                   │  只读根文件系统      │
                   └──────────┬──────────┘
                              │
                 ┌────────────┴────────────┐
                 │   OverlayFS (pxe_upper)  │
                 ├────────────┬────────────┤
                 │            │            │
        ┌────────▼────┐  ┌───▼────┐  ┌───▼────────┐
        │ upper layer │  │ work   │  │ lower layer │
        │ (读写)      │  │ dir    │  │ (只读)      │
        │ /pxe_upper  │  │        │  │ pxe_rootfs_a│
        └─────────────┘  └────────┘  └─────────────┘
                                         │
                                         │ NFS 导出
                                         ▼
                                   ┌─────────┐
                                   │ x86 PXE │
                                   │ 客户端  │
                                   └─────────┘
```

## 容量规划参考

| eMMC 容量 | 系统分区 | PXE 分区 | log 分区 | 总使用 |
|----------|---------|---------|---------|--------|
| 32GB | 12.3GB | 32GB (超出) | - | ❌ 不支持 |
| 48GB | 12.3GB | 32GB | 0 (刚好) | ✅ 最低配置 |
| 64GB | 12.3GB | 32GB | 16GB | ✅ 推荐 |
| 128GB | 12.3GB | 32GB | 80GB | ✅ 最佳 |

**注意**：实际使用中，log 分区不需要预分配全部空间，可以动态增长到分区末尾。
